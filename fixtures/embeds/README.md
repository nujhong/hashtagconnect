# Standalone X embed fixtures

Run from the repository root (Python 3; no npm install or app server needed):

```sh
python3 -m http.server 5182 --bind 127.0.0.1 --directory fixtures/embeds
```

Open <http://127.0.0.1:5182/> in any browser on this computer. Enter an HTTPS X profile or post URL and choose Publish markup or JavaScript factory. Submitting reloads the whole page; the address contains the URL and method so you can paste the identical test into another browser. The initial form does not load X until submitted.

- `timeline-publish.html`: the exact anchor and script generated by publish.x.com for `kunalsahu20_`, inside a minimal HTML document. No custom JavaScript, CSS, dimensions or theme.
- `timeline-factory.html`: the same profile through X’s documented `createTimeline` call, with no options or custom CSS.
- `index.html`: configurable profile/post tester. Publish mode generates timeline anchor or post blockquote markup; factory mode calls `createTimeline` or `createTweet`. No app styling or widget options are supplied. The profile and post URL validators accept x.com and twitter.com, including ID-only post URLs.

Examples:

- <http://127.0.0.1:5182/?url=https%3A%2F%2Fx.com%2Fkunalsahu20_&method=publish>
- <http://127.0.0.1:5182/?url=https%3A%2F%2Fx.com%2Fkunalsahu20_&method=factory>
- <http://127.0.0.1:5182/?url=https%3A%2F%2Fx.com%2FXDevelopers%2Fstatus%2F1346889436626259968&method=publish>

The HTML files can also be opened directly as files, but use the HTTP URLs for comparison with the app: file origins can behave differently. The bare fixtures have no URL input; edit their handle to test another profile, or use the configurable page.

## Compare browsers

Use the same test URL in Chrome, Safari, Firefox or the in-app browser. Note the browser/version, whether X is signed in, and any existing content blockers or cross-site cookie restrictions. Open DevTools → Network before loading and record failed requests to `platform.x.com`, `platform.twitter.com` or `syndication.twitter.com`, their status, and any visible error text. Keep credentials and cookies out of shared screenshots or logs.

A loaded SDK or a returned iframe does not prove that posts rendered. Inspect the actual content. A fallback link by itself is a failed timeline render. The fixtures do not infer an HTTP status from a timeout, retry automatically, proxy X, or extract iframe contents. They make no calls to the app, OAuth, Jev or the paid X REST API. X’s widget makes its own network requests.

These fixtures are outside `public/`, so the app build does not publish them. Serve only this directory, not the repository root containing local credentials.

Sources: [X Publish](https://publish.x.com/), [profile markup and factory](https://docs.x.com/x-for-websites/timelines/guides/profile-timeline), [post factory](https://docs.x.com/x-for-websites/javascript-api/guides/scripting-factory-functions).
